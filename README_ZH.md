## 我目前在做什么

- **Traceability System（可追溯系统）** — 工业 Web 应用，将产品、批次、流程与质量数据关联成可审计的历史记录。
- **[Project Nova / Hashkrieg](https://github.com/VibecodingGermany/Project_Nova) 的 [Nova.AiLab](https://github.com/arn-c0de/Nova.AiLab)** — 为 该游戏 按分支模拟和诊断 RTS AI；未观察到的实战效果不作推断。
- **FLUID** — 智能体驱动的生成式 UI 系统，测试本地、云端及混合部署。
- **ARIS** — 可自托管的多模型语音智能体，工具可扩展，面向边缘设备。
- **DeepVision-Web** — 私有的设备端 PCB 视觉追溯试点；相机画面保留在设备上。
